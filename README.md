# Favela Hostel

Site institucional (bilingue PT/EN) do **Favela Hostel**, na Travessa Roma, 5, Rocinha, Rio de Janeiro/RJ.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```

## Nota

Tipos de dormitório, comodidades, valores, programação de tours e fotos devem ser confirmados com o hostel antes da publicação oficial. O site não afirma funcionamento 24 horas.
